Gemini Canvas로 화면 만들기

실습 웹페이지 4번 탭
코드는 읽지 않아도 돼요
🎨 만드는 순서
  1. gemini.google.com 로그인 (Google 계정)
  2. 입력창 아래 도구 → Canvas 켜기
  3. 3번 탭에서 받은 프롬프트 붙여 넣고 보내기
  4. 코드가 다 써지면 미리보기 클릭
  5. 학생처럼 직접 눌러 보기
✅ 미리보기 점검 3가지
내용이 맞나요?
정답·용어·해설이 교과서와 같은지 — AI도 틀립니다!
눌러지나요?
모든 버튼·입력·다시 하기가 동작하는지
휴대폰에서도?
화면을 좁혀도 글씨·버튼이 잘 보이는지
✓Canvas 버튼이 안 보이면 부탁문 앞에 "Canvas에서"라고 쓰거나, 옆 선생님과 함께 진행하세요.

7/9페이지

학생에게 주기 전 체크

공유 전 체크, 그리고 기억할 세 가지
✅ 공유 전 체크리스트
  • 정답·해설을 교과서와 대조했다
  • 학생 개인정보를 입력받지 않는다
  • 교과서 본문·그림을 통째로 넣지 않았다 (저작권)
  • 휴대폰·크롬북에서 직접 열어 보았다
  • 인터넷이 안 될 때의 대안이 있다
1. 내용은 교사가 — 학습 내용을 직접 넣고, 정답·해설은 반드시 확인
2. 화면은 AI가 — 코드는 몰라도 OK, 미리보기 보고 말로 고치기
3. 작게 시작 — 다음 주 도입 퀴즈 5문항부터
